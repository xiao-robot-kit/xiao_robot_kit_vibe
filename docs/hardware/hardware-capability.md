## 0. 30 秒能力速览

| 你想玩 | 板上资源 | 接口 |
|---|---|---|
| 双路有刷电机正反转/调速/编码器测速闭环 | 2× GC9112 H 桥驱动(U14=M1,U16=M2) | J4/J6(GH 1.25mm 2P)直流电机口;J8/J9(ZH 1.5mm 6P)编码器电机口——**两对口共享同一对输出** |
| 四路舵机(云台/机械臂/转向) | 4× 独立 PWM(50Hz LEDC) | J1=S1、J5=S2、J13=S3、J14=S4(2.0mm 4P) |
| WS2812 灯效 | D13 → 3.3→5V 电平缓冲(74LVC1G17)→22R | J7(2.0mm 4P),灯带供电 5V 已备好 |
| 姿态/运动检测 | 板载 LSM6DS3TR-C 六轴 IMU(I2C,轮询) | 板载,无中断线 |
| IMU 温度稳定标定 | D12 PWM → NMOS → 加热电阻(闭环恒温) | 板载 |
| I2C 传感器扩展 | 一条 I2C 总线 ×2 个 Grove 口 | J11、J12(与板载 IMU 共总线) |
| 串口对接 | UART0(TX/RX,0R 跳线) | J10(Grove 4P) |
| 电池供电+电量监测 | 1S 锂电座 + 充电管理 + ADC 分压采样 | J3(JST-PH 2.0) |
| USB 烧录/调试/供电 | USB 2.0 Type-C,USB CDC 串口日志 | 板载 |

**一句话**:这是一块「ESP32-S3 双电机闭环 + 四舵机 + 灯效 + IMU」的小机器人主板,20 个 GPIO 全部用满,扩展只能走 I2C/UART。

## 1. 主控与系统

- **主控**:Seeed **XIAO ESP32-S3 Plus 模块**(U3,板对板 SMD 焊接,34 焊盘),芯片 esp32s3,USB CDC 原生串口日志
- **模块供电**:VBUS(5V) ← Q10(PMOS 保护)+ R12(0R) ← VSYS_5V
- **模块 3.3V**:内部 LDO → 3V3_OUT(pad12)→ R7(0R)→ **VOUT_3V3 整轨**(对外供电)
- **系统脚**:EN/RST(K6 复位键 + R36 10K 上拉 + C14);USB_DP/DN 直连 Type-C
- **备用引脚**:模块底面 pad24(MTDI)、pad25(MTDO)引至测试点 **TP20/TP21——全板唯一可飞线的备用 GPIO**;pad28(MTMS)、pad29(MTCK)、pad32(VBAT)悬空

## 3. 对外接口逐口明细(引脚级)

### 3.1 USB-C(USB1)— 供电 + 烧录 + 调试
- 引脚:A6/B6=D+,A7/B7=D−(→模块 USB_DP/DN),A4_B9/B4_A9=VBUS,A5/B5=CC,A1_B12/B1_A12+S1~S4=GND
- 通路:VBUS →R91(0R)→Q17→Q9(保护/开关,受 SW1 `VBUS_EN` 使能)→TypeC_5V
- 能接:PC(烧录/USB CDC 日志)、5V 适配器、OTG

### 3.2 电池座 J3 — 1S 锂电输入
- 引脚:1=VBAT,2=GND;JST-PH 2.0 卧贴
- 能接:1S 锂电池(3.0~4.2V);充电由板内 BQ25886 承担;电压经 100K/30K 分压进 D16

### 3.3 直流电机口 J4(M1)/ J6(M2)— GH 1.25mm 2P
- 引脚:1=OUT+,2=OUT−(M1_OUT1/2、M2_OUT1/2)
- 能接:TT 电机、有刷直流电机(N20/130 等)

### 3.4 编码器电机口 J8(M1)/ J9(M2)— ZH 1.5mm 6P
- 引脚(J8):1=M1_OUT+,2=编码器 VCC(VOUT_3V3 经 120R 磁珠 FB3),3=ENC_A(←D3,22R+ESD),4=ENC_B(←D14),5=GND,6=M1_OUT−
- J9 同构:3=M2_ENC_A(D17),4=M2_ENC_B(D10)
- 能接:GA25/MG513 类带霍尔编码器减速电机
- **注意:J4/J6 与 J8/J9 共享同一对输出——同一通道二选一接法,勿同时接两个电机**

### 3.5 舵机口 ×4 — 2.0mm 4P(J1=S1,J5=S2,J13=S3,J14=S4)
- 引脚:1=信号(0R+ESD),2=NC,3=电源,**4/5/6=GND**
- 电源:J1/J5/J13 从 Motor_5V 经 0R(R21/R23/R90)+SMA 功率二极管+Bulk 电容;**J14 直连 Motor_5V**
- 能接:SG90/MG996 等三线舵机 ×4;注意与电机共轨的电流预算(见 §7)

### 3.6 Grove I2C 口 ×2 — J11(口①)/J12(口②),2.0mm 4P 90°
- 引脚:1=SCL(D5),2=SDA(D4),3=VOUT_3V3,4=GND(+5/6 壳接地)
- **与板载 IMU 同一条总线**(地址规划见 §6)
- 能接:温湿度/光照/TOF/OLED 等任何 I2C 模块 ×2

### 3.7 Grove UART 口 J10 — 2.0mm 4P 90°
- 引脚:1=TX(D6),2=RX(D7),3=VOUT_3V3,4=GND
- 能接:串口 WiFi/BT 模组、调试桥、另一块 MCU

### 3.8 RGB 灯带口 J7 — 2.0mm 4P
- 引脚:1=数据(来自缓冲器,5V 电平),2=NC,3=VSYS_5V,4/5/6=GND
- 能接:WS2812/SK6812 灯带、环形灯(数据已由 SN74LVC1G17 抬到 5V,**勿绕过缓冲直连 3.3V 信号**)

## 5. 电源架构

```
USB-C 5V ──R91──Q17──Q9(SW1 使能)── TypeC_5V ──┬──────────────┐
                                                │ BQ25886 充电  │
1S 电池(J3)──VBAT_IN──────────────────────────┴→ 电池          │
                                                    │Q8         │
                                             VBAT_LOAD           │
                                                    │U19 SY83088 │
                                              VOUT_5V(升压)      │
                                                    ├───────────┘
                                        TPS2117 双路选择(USB/电池)
                                                    ↓
                                             VSYS_5V ──┬─Q10/R12→ 模块 VBUS(5V)
                                                       └─Q7(+R16 0R)→ Motor_5V(电机+舵机)
模块内部 LDO → 3V3_OUT →R7→ VOUT_3V3(Grove 口/编码器 VCC/按键上拉)
```

- **电源轨**:VSYS_5V(系统 5V)、Motor_5V(执行器 5V,经 Q7 大电流开关)、VOUT_5V(升压输出)、VOUT_3V3(3.3V 对外)、VBAT_IN/VBAT_LOAD(电池域)
- 电池采样:VBAT_IN →R109(100K)/R74(30K)→ D16
- 充电:TypeC_5V →BQ25886(buck-boost NVDC,不占 I2C,阻容配置)→ 电池;D3/D4 红灯=充电状态(硬件)

## 6. I2C 总线专项(单总线,3 挂点)

- **一条总线**(网络名 I2C1):SDA=D4、SCL=D5;挂载 **J11、J12、板载 IMU** 三处——全工程穷举无第二条 I2C 网络
- **链路**:U3.pad6→R26(22R)→SCL;U3.pad5→R25(22R)→SDA(串阻+ESD)
- **上拉(双电源域)**:3V3 域 SDA=2.2K∥4.7K∥4.7K≈1.14K、SCL 同;IMU_VDD 域 SDA/SCL 各 4.7K(R72/R100)——IMU 独立供电域,加热/断电时总线仍有定义
- **固件注意**:①地址规划当一条总线分配;②上拉偏强(≈1.1K),400kHz 稳、1MHz 不保证;③IMU 地址 0x6A/0x6B(`[SA0 接法未逐脚验证,上电扫描确认]`);④充电 IC BQ25886 不占 I2C

## 7. 硬件约束与坑(必读)

1. **GPIO 零空余**:20 个 GPIO 全分配,新外设只能走 I2C(J11/J12,与 IMU 共总线)或 UART(J10);真备用只有 TP20/TP21 飞线
2. **舵机与电机共 Motor_5V 轨**:USB 供电时功率受限,多舵机堵转会拉垮电压——建议电压监测(P-04)联动降载
3. **RGB 数据必须走 J7**:板上有 5V 电平缓冲,直接引 3.3V 到灯带是错误接法
4. **IMU 无中断**:INT1 仅上拉未接 MCU,只能轮询/定时采样
5. **无固件可控板载 LED**:3 个 LED 全硬件驱动,可视反馈=串口+外接灯带
6. **编码器 VCC 来自模块 LDO**(3V3_OUT→R7):外接 Grove+编码器功耗都算模块 3.3V 预算
7. **0R 跳线位**(可改电路):R27/R28(UART 串接)、R35/R41/R61/R96(舵机信号)、R7(3V3 对外)、R12/R16(电源)
8. **外部信号全部 ESD+22R/0R 保护**,但 none 是隔离的——大电流仍走功率路径
9. 外壳/结构件注意:电池座卧贴、Type-C 侧出、四角 M2? `[安装孔位未从网表提取,需查 PCB 边框]`

## 9. 证据与复核方法

- 本报告全部引脚关系来自 PCB 网表逐焊盘提取 + 原理图连通分量交叉核验(提取脚本属板卡工程内部工具,未随文档发布);**复核请以实测为准**:对任意一条引脚结论,用万用表通断档在本板对应焊盘验证,或按 [periph-spec.md](periph-spec.md) 的例程上板实测。
