# 外设例程索引（P-00 ~ P-12）

13 个例程，覆盖板上**每一个外设**。每个例程一个独立 IDF 工程，可单独构建、
单独烧录，互不依赖——想验证哪颗器件就直接进对应的那个目录。

> 源码位置：`xiao_robot_kit_idf/examples/periph/P-XX_*/`
> 每个例程目录下都有 `README.md`（接线 + 输出判读 + 改参位置）与
> `run.bat`（构建+烧录+监视一条龙）。
>
> 例程跑通之后想验证「数据准不准、控制环稳不稳、参数丢不丢」，进
> **[深度实验索引](experiments-index.md)**（14 个工程）。

## 怎么用这一页

1. **先看「跑起来看到什么」这一列**——它是验收标准，看到这一行才算跑通。
2. 不确定引脚接线，查 [硬件介绍](../hardware/board.md) 的引脚分配表；
   想知道某个接口还能接什么、电源怎么走、有哪些坑，查
   [硬件能力报告](../hardware/hardware-capability.md)。
3. 想知道每个例程的**验收标准原文**（已发布 P-00~P-12 + 规划中 P-13 深睡、按波次上板顺序），见
   [例程规格](../hardware/periph-spec.md)。
4. 没实物板？每个例程都能用 `run_qemu.bat` 做 SIM 变体编译验证
   （合成数据源，不接实物也能确认工程可构建）。

## P-00

**hello_bringup** — 上电自检，什么都不接也能跑。

- **看到什么**：`OK boot P-00_hello_bringup` + 固件版本 + 复位原因，之后每 10s 心跳一行
- **验什么**：工具链通了、串口通了、板子在跑
- **改什么**：心跳间隔（`main/hello_bringup_main.c`）

## P-01

**imu_lsm6ds3** — 读板载六轴 IMU（I2C 轮询）。

- **看到什么**：`WHO 0x6A ok` → 总线扫描 → 100Hz 的 `IMU n=... err=0` 流
- **验什么**：5 分钟连续读零错误（`err=0`）
- **改什么**：`P_SIM_IMU` 宏切合成/真实数据；采样率走 `xiao_imu` 预设表（`imu.raw.104`）

## P-02

**button_k7** — D11 侧面按键 K7 的事件识别。

- **看到什么**：短按 / 长按事件行
- **验什么**：连按上万次不出现重复/丢失事件（消抖参数在源码顶部）
- **改什么**：消抖窗口、长按阈值

## P-03

**rgb_ws2812** — D13 → J7 的 WS2812 灯带。

- **看到什么**：全彩渐变 + 单灯定点移动
- **注意**：D13 已过 74LVC1G17 缓冲到 5V 电平，**不要绕过缓冲直接接 3.3V 灯带**
- **改什么**：灯珠数量、渐变色阶、速度

## P-04

**battery_voltage** — D16 电池 ADC（100K:30K 分压）。

- **看到什么**：`vbat=xxxx mV` + SOC%，低于阈值打告警行
- **验什么**：万用表测电池电压与打印值一致（换算 `Vbat = Vadc × 130/30`）
- **改什么**：`P_ADC_RAW` 宏切合成/真实 ADC；上下限电压、容量走 `xiao_battery` 参数

## P-05

**motor_gc9112** — 双路 GC9112 H 桥（M1/M2）。

- **看到什么**：`MOT M1 fwd duty=+0.50 rpm=... (sim)` 动作序列 + 占空比-转速曲线，
  最后收尾 `MOT DONE m1=... m2=...`
- **注意**：J4/J6（直流口）与 J8/J9（编码器口）**共享同一对输出**，不要同时接两种电机
- **真硬件档**：LEDC HAL 属 port 层，公开仓只提供 SIM HAL——`P_SIM_MOTOR=0` 会编译期
  显式拒绝（不会静默编出假固件）

## P-06

**encoder_read** — 编码器计数 + 闭环。

- **看到什么**：`ENC PIK count=...`（手转计数）→ `ENC DRIVE target=+120`（闭环到目标）
- **验什么**：手转一整圈计数与减速比换算一致；闭环残差收敛
- **依赖**：电机输出与 P-05 同源

## P-07

**servo_pwm** — 4 路 50Hz 舵机（J1/J5/J13/J14）。

- **看到什么**：`SERVO vbat=7.40 ang0=0/90/180` 定位序列 + `WARN vbat=6.00` 电压联动告警
- **注意**：与电机共享 `Motor_5V` 轨，多舵机堵转时注意电流预算
- **改什么**：`P_ADC_RAW` 切合成/真实电压；各舵机中位与行程

## P-08

**i2c_scan_ports** — I2C 总线枚举（J11/J12 与板载 IMU 共总线）。

- **看到什么**：`SCAN dev=0x6A kind=KNOWN`（板载 IMU）→ `dev=0x40 kind=NEW`（外扩）→ 地址表轮次
- **验什么**：插上新传感器后扫描能报 `NEW`
- **改什么**：`P_SIM_SCAN` 切合成/真实扫描

## P-09

**uart_passthrough** — J10 Grove UART 环回/透传（D6/D7）。

- **看到什么**：`LOOP n=1 tx=1000 rx=1000 loss=0 crc=OK` 逐轮推进
- **验什么**：115200 双向 10 分钟零丢包、CRC 全对
- **注意**：D6/D7 串了 0R 跳线，与 USB CDC 日志并存不冲突

## P-10

**imu_heater** — IMU 恒温闭环（D12 PWM → NMOS → 加热电阻）。

- **看到什么**：`HT r=10 t=45.1 st=HOLD d=0.12`（恒温保持）→ `st=OVERHEAT`（超温保护）
  → `WDT fail seq=3`（看门狗）
- **验什么**：目标温度 ±2°C 内稳定；超温强制关断；温补系数写入 `xiao_calibration`
- **安全**：这是**唯一会发热**的例程，超温保护不许关
- **说明**：温度源是 IMU 芯片内置温度计（板面无独立热敏电阻）

## P-11

**pstore_params** — 参数持久化（flash 裸分区 `store`）。

- **看到什么**：写参数 → `reset` → 重启后读回值一致 + `boot_count` 递增
- **验什么**：断电重启（真断电，不是复位）后参数不丢
- **介质**：`partitions.csv` 定义了 64KB `store` 分区

## P-12

**spare_gpio_tpxx** — 全板唯一可飞线的备用 GPIO。

- **前提**：需要把 TP20（MTDI）/TP21（MTDO）测试点飞线到你要接的东西
- **看到什么**：`SPARE r1 out=1 -> in=0 PASS` 输入输出轮转行，以及 strapping 警告行
- **注意**：MTDI/MTDO 是 **strapping 引脚**——上电瞬间的电平会影响启动模式，
  用它做输出前先确认不影响烧录（例程会主动打印
  `SPARE strapping-warn GPIO42=MTDO=TP21 is VDD_SPI strap pin` 提醒你）

## 找不到你要的外设？

板上 **20 个 GPIO 全部占用**，扩展只能走两条路：

- **I2C**：J11/J12 两个 Grove 口（与板载 IMU 同总线），能挂 I2C 传感器
- **UART**：J10 Grove 口（D6/D7），能对接串口模组

其余只能靠 TP20/TP21 飞线（见 P-12）。完整引脚表见
[硬件介绍](../hardware/board.md)。
