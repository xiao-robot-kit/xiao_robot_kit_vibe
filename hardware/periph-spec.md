# XIAO Robot Board V1.0 — 外设例程开发任务书

> 版本:2026-11-06 · 派发人:硬件负责人 · 状态:待认领
> 引脚数据来源:PCB 网表逐焊盘提取并经原理图交叉校验。
> **所有引脚号均为网表实测,不是猜测。**

---

## 0. 目标与范围

为 XIAO Robot Board V1.0 的**全部外设**各写一个可独立运行的例程,按第 4 节验收标准
逐项上板实测后合入。范围 = 下表 P-00 ~ P-13（其中 P-00~P-12 已随源码仓发布，**P-13 深睡尚未实现**）；每例程一个目录,互不依赖(综合例程除外)。

主控:**XIAO ESP32-S3 Plus 模块(U3,板对板 SMD)**,芯片 esp32s3。

### 1.2 板载器件

| 器件 | 总线/引脚 | 备注 |
|---|---|---|
| U18 LSM6DS3TR-C(六轴 IMU) | I2C1(D4/D5),**与 J11/J12 共总线** | **INT1 未接 MCU**,只能轮询;独立供电域 IMU_VDD |
| U14 / U16 GC9112(电机驱动 ×2) | PWM:D1/D2、D19/D18 | 单 H 桥 ×2,Motor_5V 供电 |
| U5 BQ25886(充电) | **不占 I2C**,阻容配置独立运行 | D3/D4 红灯=充电指示(硬件驱动) |
| D1 绿灯 | — | 3.3V 电源指示,**硬件驱动,无固件接口** |
| U9 TPS2117 + U19 SY83088 | — | 电源选择/升压,无软件接口 |

### 1.3 电源轨(例程功耗预算依据)

```
USB-C / 电池 → VSYS_5V ─ Q7 → Motor_5V(4 个舵机口 + 2 个电机驱动)
                     └ Q10 → XIAO_VBUS(模块 5V)
模块内部 LDO → 3V3_OUT → R7(0R) → VOUT_3V3(Grove 口供电 + 编码器 VCC,经 120R 磁珠)
```

## 2. 开发环境(默认约定,如需改动在认领时提出)

- **框架:ESP-IDF v5.x**(目标 esp32s3);若走 Arduino 框架,接口名对应替换,验收标准不变。
- 例程目录:`examples/periph/<P-xx>_<短名>/`,每个含:
  - `main.c`(或按组件惯例)
  - `README.md`:接线表、预期现象、构建命令、已知限制
- 组件对接:与 [`xiao_robot_kit_idf`](../tutorials/idf.md) 组件库已有组件(imu / attitude / motor / pstore / battery / calibration / imu_heater / proto)的接口
  以各组件头文件注释为准;例程先直接调组件 API,组件缺 API 时**只提需求不改组件**。
- 串口日志走 **USB CDC**(板上无固件可控 LED,调试可视输出一律串口 + J7 灯带)。

|---|---|---|---|

## 4. 硬件约束(写进每个例程的注释头)

1. **GPIO 无空余**:20 个 GPIO 全占用,扩展只能走 I2C(J11/J12,与 IMU 共享)或 UART(J10)。
2. **I2C 上拉偏强**:SDA/SCL 等效约 1.05K(2.2K∥4.7K×3,已确认全部贴装),总线电容大时注意速率降级;当前 400kHz 可用,1MHz 不保证。
3. **IMU 无中断线**(INT1 仅上拉未接 MCU):一律轮询或定时采样,勿等中断。
4. **舵机与电机共 Motor_5V 轨**:USB 供电时轨功率受限,多舵机堵转会拉垮电压——例程必须做电压监测(P-04)联动告警。
5. **RGB 数据线已 5V 电平缓冲**(U4 SN74LVC1G17):直接从 D13 引 3.3V 信号到灯带是错误接法,必须走 J7。
6. **电池 ADC 分压比 100K:30K**(Vbat×30/130≈0.231,满电 4.2V→约 0.97V,3.0V→约 0.69V,均在 ADC 12dB 衰减量程内):校准系数可存 pstore。
7. **充电指示灯(红×2)、电源灯(绿)均为硬件驱动**,固件无接口,不要写"LED 状态读取"类代码。
8. **编码器/外设 3V3 来自模块 LDO**(3V3_OUT→R7):外接 Grove 器件功耗计入模块供电预算。

## 5. 验收流程与汇报纪律

5.1 **每例程交付物**:源码 + README + **上板实测记录**(串口日志原文 + 现象照片/视频)。
5.2 未上板实测的一律标注「未验证」,禁止虚报通过(此为团队硬纪律)。
5.3 电流类验收(舵机/电机/加热)需记录供电方式(USB/电池)与实测电流。
5.4 踩坑返工必须回报并沉淀到 `.ai/errors/`(任务卡随附)。
